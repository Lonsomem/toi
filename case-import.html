📥 사건목록 가져오기

내부 시스템 JSON → 필요한 키만 선별 · 외부 통신 없음(입력한 주소로만 접속)

1. 데이터 가져오기

JSON 안에서 사건 배열이 들어있는 위치를 직접 지정합니다. 점(.)으로 단계를 구분합니다 (예: data.myCaseListVo는 {"data":{"myCaseListVo":[...]}} 구조를 가리킴). 비워두면 자동으로 배열을 찾습니다.

[가져오기]는 이 페이지가 그 주소로 직접 접속해 JSON을 가져옵니다. 다른 서버로는 통신하지 않습니다. 다만 브라우저의 교차출처 정책(CORS) 때문에 대상 시스템이 허용하지 않으면 실패할 수 있습니다 — 그런 경우 [🔗 새 탭에서 열기]로 직접 연 뒤, 그 탭에서 전체 선택(Ctrl+A) · 복사(Ctrl+C)하고 [📋 직접 붙여넣기] 탭의 [클립보드에서 붙여넣기]를 사용하거나, 개발자도구 콘솔에서 직접 .json 파일로 저장해 [📁 파일] 탭으로 불러오세요.

다른 탭에서 JSON 페이지를 전체 선택(Ctrl+A)·복사(Ctrl+C)한 다음 위 버튼을 누르면 자동으로 채워집니다. 처음 누르면 브라우저가 클립보드 읽기 권한을 물어볼 수 있습니다 — 허용해야 동작합니다. 안 되면 아래 칸에 직접 Ctrl+V로 붙여넣어도 됩니다.

로컬 .json 파일을 선택하면 바로 읽어서 불러옵니다. (예: 개발자도구 콘솔에서 fetch 결과를 .json 파일로 저장해둔 것)

3. 미리보기

사건 관리 노트와 사건번호로 매칭해 불러오는 기능은 다음 단계에서 추가될 예정입니다.

4. 사건별 상세정보 가져오기 (선택)

사건번호 등 "사건번호로 쓸 키"로 지정한 값을 URL에 넣어, 사건마다 상세 정보를 추가로 가져옵니다. URL 안에 {값} 이라고 쓰면 그 자리에 각 사건의 매칭 키 값이 들어갑니다. 사건 수만큼 순서대로 접속하므로 수가 많으면 시간이 걸릴 수 있고, 각 사건 접속도 동일한 교차출처 정책(CORS) 제약을 받습니다.

상세 응답에서 발견된 키 중 결과에 포함할 것을 선택하세요. (이미 있는 키 이름과 겹치면 상세_를 붙여 구분합니다)

5. 값 형식 변환 (선택)

특정 키의 값 형식을 일괄 정리합니다 (정규식으로 찾아서 바꿈). 상세정보까지 다 가져온 뒤, 저장하기 직전에 적용하는 것을 추천합니다 — 먼저 바꿔버리면 "4. 사건별 상세정보 가져오기"가 원래 형식을 기대하는 경우 매칭이 안 될 수 있습니다.
