# 내부망 로컬 LLM (Qwen) 도입 검토 메모

> **2026-11-17 작성**: 아직 **미구현**. QR 코드로 매뉴얼/JSON 을 내보내는 대신, 내부망 PC에 경량 LLM 을 직접 올려서 쓰는 방향을 검토한 결과 메모. 코드·스크립트는 없음 — 반입 절차와 모델 선택 판단만 기록.

## 1. 배경
기존 QR 전송(`docs/qr-transfer.md`) 은 "매뉴얼을 추출해서 외부로 꺼내는" 방향이었다. 이번 안은 반대로 **매뉴얼/지식 JSON 을 내부망 PC 안에서 로컬 LLM 이 직접 읽고 답하게** 하는 방향. 외부 통신 없이 돌아가야 하므로(이 저장소 전체 원칙과 동일), 파인튜닝보다 RAG(검색 후 생성) 쪽이 적합하다고 판단함.

- 파인튜닝: 매뉴얼만으로는 입력-정답 학습 쌍이 부족하고, 아래 사양으로는 LoRA 조차 VRAM 이 부족함.
- RAG: 학습 불필요, 매뉴얼이 바뀌어도 재학습 없이 바로 반영, 답변에 **출처 쪽 번호**를 그대로 붙일 수 있어 이 저장소의 "모든 항목에 출처 쪽" 원칙과 맞음.

## 2. 대상 하드웨어
- RAM 16GB, **VRAM 없음(통합 그래픽 가정)** → 순수 CPU 추론.
- CPU 추론 기준 예상 속도: 초당 2~8 토큰 (질문 1건당 수 초~1분 내 응답 예상, 사용자 실측 전까지는 추정치).

## 3. 모델 선택
| 모델 | 판단 |
|---|---|
| **Qwen2.5-7B-Instruct** (GGUF Q4_K_M, ~4.7GB) | **1차 후보.** 다국어 지원 명시, 추론형이 아니라 일반 질의응답에 적합, 16GB RAM 에 여유 있음 |
| DeepSeek-R1-Distill-Qwen-7B | 비추천. 추론 특화 모델이라 답변 전에 "생각 과정" 토큰을 길게 생성 → CPU 전용 환경에서 체감 속도 더 느림. 한국어 품질 검증 자료도 부족 |
| Qwen3-8B | 대안. Qwen2.5-7B 테스트 결과가 부족하면 다음으로 시도 |

실행 도구: **Ollama** (내부에서 llama.cpp 사용, 완전 오프라인 실행 가능).

## 4. 내부망 반입 절차 (인터넷이 되는 환경이 따로 필요)
1. **외부(인터넷 되는) PC**: Ollama 설치 → `ollama pull qwen2.5:7b-instruct` 실행. `~/.ollama/models` 아래에 모델 파일이 생성됨.
2. Ollama 자체의 **설치 스크립트는 오프라인에서 동작하지 않음** — 설치 스크립트가 아니라 standalone 바이너리를 따로 받아야 함.
3. **반입**: Ollama 바이너리 + `.ollama` 폴더 전체를 조직이 승인한 경로(USB 등)로 내부망에 반입. 반입 전후 SHA-256 해시를 비교해 손상 여부 확인 권장.
4. **내부망 PC**: 바이너리 설치 후 같은 경로에 `.ollama` 폴더를 그대로 복사 → `ollama run qwen2.5:7b-instruct` 로 추가 다운로드 없이 바로 실행.
5. 모델 업데이트는 매번 1~4 과정을 수동으로 반복해야 함(자동 업데이트 없음) — 내부망 특성상 당연한 제약으로 보고 감수.
6. GGUF 메타데이터가 오래된 버전(v3 미만)이면 "모델 로드 실패"가 날 수 있다는 보고가 있음 — 받을 때 최신 GGUF인지 확인.

## 5. RAG 구성안
- **소스**: `pdf-manual-search.html` 로 이미 추출한 매뉴얼 텍스트/표를 그대로 재사용 (3단계 "죄명별 지식 JSON" 과 연결).
- **임베딩 모델**: **KURE-v1** (한국어 특화, bge-m3 기반 파인튜닝, MIT 라이선스). 모델도 2~4단계와 같은 방식(외부 반입)으로 준비.
- **검색**: 매뉴얼 규모가 크지 않으면 별도 벡터DB 없이 코사인 유사도로도 충분. 규모가 커지면 로컬 벡터DB(Chroma 등) 추가 검토.
- **생성**: 검색된 조각 + 쪽 번호를 프롬프트에 넣어 Qwen 이 답변 생성. 답변에 항상 출처 쪽을 표시.

## 6. 한계 / 검증 안 된 것
- CPU 추론 속도·실제 한국어 답변 품질은 **이 저장소 컨테이너(클라우드, VRAM 없음이지만 CPU/RAM 사양이 대상 PC와 다름)에서의 추정치**이며, 실제 대상 PC에서 실측 전까지는 단정할 수 없음.
- 네트워크 정책상 이 개발 컨테이너에서 Ollama 호스트(`ollama.com`, `registry.ollama.ai`) 접근이 기본적으로 막혀 있어, 직접 다운로드·실측 테스트는 사용자 승인(환경 네트워크 허용 목록 추가) 또는 인터넷이 되는 별도 PC에서 진행해야 함.
- 7~8B 급 모델은 환각 가능성이 있음 — **법적 판단은 모델이 하지 않고 사람이 항상 확인**한다는 원칙은 그대로 유지.
- 파인튜닝은 보류. 실제 사용 로그(질문-좋은 답변 쌍)가 쌓이면 가벼운 LoRA 보완을 나중에 재검토.
