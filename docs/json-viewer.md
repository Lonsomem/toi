# JSON 뷰어 (json-viewer.html)

> **2026-11-19 신규**: 범용 JSON 트리 탐색기. 특정 기능(사건 관리 노트 등)에 종속되지 않는 독립 도구 — 어떤 JSON이든 구조를 모르는 상태로 가져와서 시각적으로 펼쳐보고, 검색해서 원하는 값의 경로·값을 바로 복사할 수 있음.

## 배경
`case-import.html` 작업 중 "JSON 안에서 특정 정보를 찾을 때 시각적으로 찾는 게 낫겠다"는 요구로 별도로 분리해 만듦. 앞으로 어떤 JSON 작업에서든 범용으로 재사용 가능.

## 기능
- **데이터 불러오기 3가지**: 붙여넣기 / 로컬 .json 파일 선택 / URL(fetch, CORS 막히면 붙여넣기로 대체 안내) — `case-import.html`과 같은 패턴.
- **트리 보기**: 루트 + 1단계는 기본으로 펼쳐짐, 그 아래는 접힘. 객체는 `{ } 객체 · N개 키`, 배열은 `[ ] 배열 · N개 항목`으로 요약 표시. 키/값에 색상 구분(문자열·숫자·불리언·null).
- **모두 펼치기/접기**: 노드가 5,000개를 넘으면 모두 펼치기 전에 확인창을 띄움(느려질 수 있음을 경고).
- **검색**: 키 이름과 값 전체를 대상으로 부분 일치 검색(대소문자 무시). 일치 건수와 이전/다음 이동 제공, 이동 시 조상 노드를 자동으로 펼치고 노란색으로 잠깐 강조.
- **항목 클릭 → 경로 표시 + 복사**: `root.cases[0].suspect.name` 형태의 JS 스타일 경로를 보여주고 클립보드로 복사. 값도 별도로 복사 가능(객체/배열이면 들여쓴 JSON으로, 아니면 텍스트로).

## 구현 메모 (버그 수정 이력)
- 처음 구현에서 트리 토글·검색 경로 복원에 **JSON.stringify한 경로를 HTML `onclick` 속성 문자열 안에 직접 끼워 넣는 방식**을 썼다가, 키 이름에 작은따옴표(`'`)가 있으면 HTML 엔티티 디코딩 후 JS 문자열이 끊겨 오류가 나는 문제를 발견 → **모든 토글·선택은 미리 매겨둔 단순 숫자 id(`n0`, `n1`, ...)로만 참조**하도록 수정. Playwright로 `it's him`처럼 작은따옴표가 포함된 값을 펼쳐도 오류 없는지 확인함.
- 경로를 배열로 표현할 때 각 구간을 `{k, isIndex}` 형태로 통일해야 트리 렌더링과 검색·모두펼치기가 같은 경로 문자열을 가리킴 — 한쪽에서 `isIndex` 속성을 빠뜨리면 같은 경로인데도 다른 키로 취급되어 검색 결과로 이동해도 해당 노드가 안 열리는 문제가 있었음. 전부 통일해서 수정함.

## 검증한 것 / 안 한 것
- Playwright로 확인(총 18건): 붙여넣기/파일/URL(CORS 허용·미허용) 3가지 로드 경로, 기본 펼침 깊이, 작은따옴표 포함 키·값 펼치기, 경로·값 복사, 검색(값/키 이름 모두) 및 조상 자동 펼침, 모두 펼치기/접기, 잘못된 JSON 에러 처리.
- 대용량 JSON(수만 건 이상)에서의 실제 체감 속도는 검증 안 됨 — 토글할 때마다 트리 전체를 다시 그리는 단순한 방식이라, 노드가 아주 많으면 느릴 수 있음(5,000개 이상이면 모두 펼치기 시 경고).
