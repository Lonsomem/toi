# qr-tools

오프라인 QR 파일 전송 도구의 소스. 결과물은 저장소 루트의 단일 HTML 두 개입니다.

- `qr-sender.html`  : PC용 송신기 (파일 → [선택: 사진 축소] → 압축 → 연속 QR 재생)
- `qr-receiver.html`: 폰용 수신기 (카메라/영상 → 복원 → 다운로드)

수정은 `qr-tools/src/` 에서 하고 `python3 qr-tools/build.py` 로 다시 빌드합니다.
`vendor/jsQR.js` 는 jsQR(Apache-2.0) 원문이며 수신기에만 포함됩니다.

## 전송 방식 요약
- 구간(기본 512KB)마다 원본 블록 K개 + 무작위 선형 복구 조각(GF(2))을 전송. 수신은 빠진 블록 수 + 3~4개 조각이면 가우스 소거로 복원.
- 1회차: K/(1-예상손실)+3 프레임, 2회차부터 0.15K+4 프레임의 새 조각만 보충.
- 프레임 헤더 bit7 = RGB 3층 여부(수신기 색상 모드 자동 전환용).
- 속도 보정 테스트: 송신기가 여러 단계(V12~V30, fps, ECC, 흑백/RGB)를 재생하면 수신기가 단계별 실효 속도를 표로 보여줌.
